## Компоненты

### 1. Chrome Extension

**Side Panel UI** (React + Vite + Tailwind, `frontend/src/sidepanel/`)
- Боковая панель вместо popup: не закрывается при потере фокуса и не обрывает запись
- Режим «Голос»: запись с микрофона, вкладки со звонком или обоих источников (MediaRecorder, WebM/Opus)
- Режим «Текст»: вопрос вводится вручную и сразу уходит в Qwen
- Отображение транскрипции, ответа (markdown), истории; настройки в `chrome.storage.local`

**Permission page** (`src/permission/`)
- Боковая панель не показывает запрос доступа к микрофону, поэтому он запрашивается в отдельной вкладке один раз

**Background Service Worker** (`src/background/`)
- Открывает боковую панель по клику на иконку

### 2. Backend Server

**API Layer (FastAPI)**
- `/api/transcribe` - преобразование аудио в текст
- `/api/generate-answer` - генерация ответа на вопрос
- `/api/health` - проверка состояния сервисов

**STT Service (Whisper)**
- Модель: faster-whisper (medium)
- Поддержка русского и английского
- Локальное выполнение

**LLM Service (Ollama)**
- Модель: Qwen 3 (qwen3:4b)
- Генерация структурированных ответов
- Контекстное понимание вопросов

## Поток данных

1. **Захват аудио**
   - Пользователь нажимает кнопку записи в боковой панели
   - Панель захватывает микрофон и/или звук вкладки (`chrome.tabCapture`)
   - Аудио буферизируется в памяти и по остановке отправляется одним файлом

2. **Транскрипция**
   - Аудио отправляется на `/api/transcribe`
   - Whisper преобразует в текст
   - Текст возвращается в расширение

3. **Генерация ответа**
   - Текст вопроса отправляется на `/api/generate-answer`
   - LLM генерирует ответ с учетом контекста
   - Ответ отображается в боковой панели

4. **Отображение**
   - Результат показывается в боковой панели и сохраняется в историю

## Технические детали

### Требования к производительности
- Латентность STT: < 2 секунды (для 30 сек аудио)
- Латентность LLM: < 5 секунд
- Использование RAM: ~4-6 GB
- Использование CPU: умеренное (оптимизация через int8)

### Безопасность
- Все данные обрабатываются локально
- Нет отправки данных на внешние серверы
- API доступен только для localhost

### Расширяемость
- Модульная архитектура
- Простая замена моделей
- Возможность добавления новых источников аудио
